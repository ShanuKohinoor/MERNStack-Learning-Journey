5• Use $group to find total and average revenue for each category.
run:- 

  school>  db.sales.aggregate([{$group:{_id:"$category",total:{$sum:"$revenue"},average:{$avg:"$revenue"}}}])


oiutput will be:- 
[
  { _id: 'Furniture', total: 1800, average: 900 },
  { _id: 'Stationery', total: 179, average: 59.666666666666664 },
  { _id: 'Electronics', total: 7600, average: 2533.3333333333335 }
]




6• Sort results by total revenue (highest first).

run:-
school> db.sales.aggregate([{$group:{_id:'$category',total:{$sum:'$revenue'},average:{$avg:'$revenue'}}},{$sort:{total:-1}}])


output will be:-
[
  { _id: 'Electronics', total: 7600, average: 2533.3333333333335 },
  { _id: 'Furniture', total: 1800, average: 900 },
  { _id: 'Stationery', total: 179, average: 59.666666666666664 }
]




 7• Show top 2 categories using $limit.

 run:-
 school> db.sales.aggregate([{$group:{_id:'$category',total:{$sum:'$revenue'},average:{$avg:'$revenue'}}},{$sort:{total:-1}},{$limit:2}]) 

 output will be:-
 [
  { _id: 'Electronics', total: 7600, average: 2533.3333333333335 },
  { _id: 'Furniture', total: 1800, average: 900 }
]      





8• Use $bucket to group items by price range.
   run:-
     db.sales.aggregate([{$bucketAuto:{groupBy:'$price',buckets:3}}])

  output will be:-
       [
        { _id: { min: 2, max: 30 }, count: 3 },
        { _id: { min: 30, max: 300 }, count: 3 },
        { _id: { min: 300, max: 800 }, count: 2 }
      ]
